## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Mouseover Scores** | See any player's Mythic+ rating by hovering their character |
| **Raid Progress** | Current and previous tier raid progress for any guild or player |
| **Keystone History** | Recent Mythic+ runs with timing and affix details |
| **Group Finder** | Filter LFG applicants by their Raider.IO score in-game |
